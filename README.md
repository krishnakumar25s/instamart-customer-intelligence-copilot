# Instamart Customer Intelligence & Support Copilot

## Project Overview

The **Instamart Customer Intelligence & Support Copilot** is a Python-based data analytics and AI-assisted customer support project. It combines customer segmentation, customer lapse prediction, support-ticket classification, policy retrieval, and a simulated refund-support agent in a single workflow.

The project is organized into four major parts:

- **Part A:** Data generation, auditing, cleaning, and validation.
- **Part B:** Exploratory data analysis, RFM analysis, customer segmentation, and lapse prediction.
- **Part C:** Support-ticket classification, PII redaction, retry handling, and token-budget evaluation.
- **Part D:** Policy retrieval and a refund-support agent with eligibility checks, simulated refunds, human escalation, and loop detection.

## Key Features

### 1. Data Preparation
- Generate synthetic Instamart datasets.
- Audit data quality and identify potential issues.
- Clean and validate datasets.
- Store cleaned data in SQLite for downstream analysis.

### 2. Customer Intelligence
- Perform exploratory data analysis.
- Calculate Recency, Frequency, and Monetary (RFM) metrics.
- Segment customers using K-Means clustering.
- Train a customer lapse-prediction model.
- Generate customer retention recommendations and feature-importance outputs.

### 3. Support-Ticket Intelligence
- Classify tickets into support categories.
- Compare zero-shot and few-shot classification.
- Redact detected personally identifiable information (PII).
- Handle simulated transient errors and retry attempts.
- Evaluate classification accuracy, token usage, and budget limits.

### 4. Refund Support Copilot
- Look up order details in SQLite.
- Retrieve relevant policy passages using TF-IDF and cosine similarity.
- Calculate refund eligibility from order status, delivery time, and order amount.
- Simulate automatic refunds for eligible amounts up to ₹1,000.
- Escalate refunds above ₹1,000 for human approval.
- Detect repeated tool calls and stop looping behavior.

## Technology Stack

- **Language:** Python
- **Data processing and analysis:** pandas, NumPy
- **Machine learning:** scikit-learn
- **Visualization:** Matplotlib
- **Model persistence:** joblib
- **Database:** SQLite

SQLite and Python's regular-expression functionality are available through Python's standard library. The exact third-party package versions should be recorded from the working virtual environment.

## Setup

### Prerequisites

- Python 3.13, matching the development environment used for this project.
- Visual Studio Code or another Python-compatible editor.
- PowerShell or a compatible terminal.

### 1. Open the project directory

```powershell
cd "$HOME\Downloads\instamart-copilot"
```

### 2. Activate the virtual environment

```powershell

```

Run commands from the project root with the virtual environment activated. Follow the order below because later stages depend on files generated by earlier stages.

### Support-Ticket Classification

Recorded results from the classification experiment:

| Metric | Zero-shot | Few-shot |
|---|---:|---:|
| Classified tickets | 147 | 147 |
| Accuracy | 85.71% | 100.00% |
| Total tokens | 11,428 | 22,348 |
| Tokens per classified ticket | 77.74 | 152.03 |

The few-shot experiment achieved higher accuracy on this evaluation dataset while using more tokens. These results describe the supplied mock-model experiment and should not be interpreted as a guarantee of performance on real customer tickets.

The budget demonstration used a nominal 6,000-token limit. Its recorded usage was 6,021 tokens, reflecting the current implementation's budget-check behavior.

### Refund-Agent Tests

The following scenarios were demonstrated during development:

| Scenario | Observed outcome |
|---|---|
| Completed order delivered within 45 minutes | Refund denied |
| Unknown order ID | Order not found |
| Missing order ID | Requests the order ID |
| Completed order, ₹12, delivered in 74 minutes | Simulated automatic refund issued |
| Completed order, ₹2,598, delivered in 62 minutes | Escalated to a human support lead |
| Cancelled order | Refund denied |
| Repeated tool call | Loop detected and stopped |

The refund policy requires a completed order and delivery later than 45 minutes for a late-delivery refund. Amounts up to ₹1,000 are handled by the simulated automatic-refund path; larger amounts require human approval.

## Limitations

- The datasets are synthetic and may not represent real Instamart customer behavior.
- `mock_llm.py` is a deterministic stand-in, not a connection to a live commercial LLM.
- Refund issuance and escalation are simulated; no actual payment or refund is processed.
- Model performance on the generated dataset may differ from performance on real-world data.
- Policy retrieval uses TF-IDF and cosine similarity rather than a neural embedding model.
- The project is a demonstration and requires additional security, testing, monitoring, and integration work before production deployment.
